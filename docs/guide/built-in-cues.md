# 内置动画

当前版本提供以下内置动画：

| 命令 | 用途 |
| --- | --- |
| `confetti` | 全屏彩纸庆祝 |
| `task-complete` | 底部彩带、完成提示和成功音效 |
| `success` | 成功标记 |
| `milestone` | 里程碑光环 |
| `focus-start` | 开始专注 |
| `error` | 错误抖动 |
| `silent-confetti` | 静音彩纸 |

使用命令行查看当前清单：

```powershell
motion-cue list --json
```

使用 `motion-cue stop` 可以停止当前播放。
