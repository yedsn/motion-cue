## Purpose

定义第三方 Web 动画如何以本地插件包形式安装和运行，同时将其能力限制在视觉渲染及受控音效事件内，避免获得系统或用户数据访问权限。

## ADDED Requirements

### Requirement: 安装结构化本地插件包
系统 SHALL 仅安装包含有效清单、入口文件、格式版本和完整资源列表的本地插件包，并在写入插件目录前验证路径、大小、文件类型和标识冲突。

#### Scenario: 安装有效插件包
- **WHEN** 用户选择一个清单和资源均通过校验的插件包
- **THEN** 系统将插件复制到独立受管理目录、登记其版本与默认命令，并保持插件默认禁用直到用户确认启用

#### Scenario: 插件包包含路径穿越
- **WHEN** 插件包包含绝对路径、`..` 路径或指向包外部的链接
- **THEN** 系统拒绝整个插件包且不在插件目录留下部分文件

#### Scenario: 插件标识已存在
- **WHEN** 用户安装与现有插件标识相同但版本不同的插件包
- **THEN** 系统明确提供升级或取消选择，升级失败时保留原插件可用状态

### Requirement: 在隔离沙箱中运行插件
系统 MUST 在与管理界面和系统桥接隔离的沙箱执行上下文中运行插件。插件 SHALL 可使用 HTML、CSS、JavaScript、Canvas、SVG，以及清单声明并获准的 WebGL 或 Worker 能力，但不得直接获得主程序 API。

#### Scenario: 插件渲染 Canvas 动画
- **WHEN** 已启用插件收到播放事件并使用 Canvas 或 SVG 渲染
- **THEN** 动画显示在目标覆盖层中，插件只能影响自身渲染容器

#### Scenario: 插件尝试访问宿主桥接
- **WHEN** 插件代码尝试调用 Tauri、Node、Rust 命令或管理界面对象
- **THEN** 对应对象不可用且调用不能到达主程序能力

#### Scenario: 插件使用未声明的高级渲染能力
- **WHEN** 插件尝试创建未在清单声明或未获准的 WebGL、Worker 等能力
- **THEN** 系统阻止该能力并记录插件诊断信息，而不扩大权限

### Requirement: 禁止插件访问外部和系统资源
插件 MUST 不得直接访问互联网、任意本地文件、系统命令、注册表、剪贴板、摄像头、麦克风、定位、通知、其他插件数据或持久化浏览器身份数据，并不得打开新窗口或导航到外部页面。

#### Scenario: 插件发起网络请求
- **WHEN** 插件尝试通过 fetch、WebSocket、图片、字体、媒体或动态脚本访问网络地址
- **THEN** 请求被阻止且不向目标发送数据

#### Scenario: 插件读取本地文件
- **WHEN** 插件尝试使用文件 URL、文件选择器、拖放句柄或宿主桥接读取包外文件
- **THEN** 系统拒绝访问，插件只能加载清单列出的包内只读资源

#### Scenario: 插件尝试持久跟踪用户
- **WHEN** 插件尝试使用 Cookie、共享本地存储或跨插件缓存保存身份数据
- **THEN** 系统不提供可跨会话或跨插件读取的浏览器身份存储

### Requirement: 通过受控 SDK 通信
系统 SHALL 向插件暴露版本化的最小 SDK，用于通知就绪、接收经过验证的播放参数、报告完成或错误，以及请求播放清单中预先声明的音效。

#### Scenario: 插件完成一次播放
- **WHEN** 插件调用 SDK 报告 `ready`、处理 `play` 事件并最终报告 `complete`
- **THEN** 主程序按生命周期关闭该会话并释放插件上下文

#### Scenario: 插件请求声明音效
- **WHEN** 插件通过 SDK 请求播放其清单中声明的音效标识
- **THEN** 主程序按用户音量、全局静音和动画配置决定是否播放该本地音效

#### Scenario: 插件发送未知消息
- **WHEN** 插件发送 SDK 未定义的消息、超长载荷或未声明音效标识
- **THEN** 主程序忽略并记录该消息，不执行任意操作

### Requirement: 限制插件资源消耗和运行时间
系统 SHALL 对插件包大小、单个资源大小、播放时长、消息频率和执行上下文生命周期设置安全限制，并允许用户随时终止插件。

#### Scenario: 插件未在就绪时限内响应
- **WHEN** 插件启动后未在规定时间内报告就绪
- **THEN** 系统终止该插件会话、隐藏覆盖层并记录启动超时

#### Scenario: 插件持续发送大量消息
- **WHEN** 插件超过 SDK 消息频率或大小限制
- **THEN** 系统丢弃超额消息，并在持续违规时终止插件会话

#### Scenario: 插件脚本崩溃
- **WHEN** 插件发生未处理异常或渲染上下文崩溃
- **THEN** 系统停止相关音效、清理会话并保持托盘和管理界面可用

### Requirement: 管理插件状态和移除
系统 SHALL 允许用户查看插件来源路径、版本、声明能力和最近错误，并支持启用、禁用、升级和卸载插件。

#### Scenario: 禁用插件
- **WHEN** 用户禁用一个插件
- **THEN** 其动画和命令停止对外可用，但插件文件和用户配置保留

#### Scenario: 卸载插件
- **WHEN** 用户确认卸载一个当前未播放的插件
- **THEN** 系统删除其受管理目录、动画登记和命令映射，不影响其他插件或配置型动画

#### Scenario: 播放期间请求卸载
- **WHEN** 用户在插件动画播放期间请求卸载
- **THEN** 系统先停止并销毁该插件会话，再执行卸载且不留下被占用资源
