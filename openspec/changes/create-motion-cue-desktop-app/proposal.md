## Why

Windows 上缺少一个可由 Hook、脚本和其他应用统一调用的轻量全屏动画工具，现有激励动画通常被重复嵌入各个业务应用，难以复用、配置和扩展。MotionCue 将动画、音效与业务逻辑解耦，让外部调用方通过稳定命令触发可信、非干扰式的全屏反馈。

## What Changes

- 创建独立的 Windows 优先桌面应用 MotionCue，常驻系统托盘并以单实例方式运行。
- 提供 `motioncue://` 自定义链接和 `motion-cue` 命令行两种调用入口，用命令名触发动画并传递经过验证的文字、颜色、时长等参数。
- 使用透明、置顶、无边框且鼠标穿透的多显示器覆盖窗口播放动画，不抢夺当前应用焦点，并在播放结束或异常超时后自动隐藏。
- 建立动画目录和命令注册表，支持命令别名、冲突校验、启停、预览、导入导出以及每个动画独立的音效配置。
- 内置彩纸、任务完成、成功、里程碑、聚焦开始、错误和静音彩纸等常用动画；任务完成动画沿用工作日报助手中已验证的左右底部彩带、顶部提示和成功音效设计。
- 支持无需编程的配置型自定义动画，允许调整受支持渲染器的颜色、数量、方向、文字、时长和音效，但不执行任意脚本。
- 支持打包式沙箱 Web 动画插件，通过受控 SDK 接收播放参数并报告状态；插件不得访问网络、任意文件、系统命令、剪贴板、设备权限或其他插件数据。
- 由主程序统一管理音效加载、音量、延迟、停止和重叠策略，并提供全局静音和单动画音效开关。

## Capabilities

### New Capabilities

- `animation-invocation`: 定义自定义链接、命令行、单实例转发、参数验证、命令解析和并发调用行为。
- `overlay-playback`: 定义多显示器透明覆盖窗口、焦点与鼠标行为、播放生命周期、队列、超时和音效编排。
- `animation-catalog`: 定义内置动画、配置型自定义动画、命令别名、音效配置、管理界面以及导入导出行为。
- `sandboxed-web-plugins`: 定义 Web 动画插件包、受控 SDK、资源加载、权限边界、隔离、安装验证和故障处理。

### Modified Capabilities

无。该项目为全新独立项目，当前不存在主规格。

## Impact

- 新建 Tauri 2、Rust、Vue 3 和 TypeScript 桌面项目，初期面向 Windows，并为后续跨平台保留接口边界。
- 引入托盘、单实例、自定义 URL 协议、命令行、多显示器窗口、配置持久化和本地资源加载能力。
- 前端使用 Canvas、CSS、SVG，并允许受控 WebGL 和 Worker；粒子动画可复用 `canvas-confetti`，音效由 Howler.js 或等价本地播放层统一管理。
- 用户配置和插件安装在应用数据目录中持久化；第一阶段不引入数据库和远程插件市场。
- 插件为纯本地离线资源，不获得通用系统权限，安装和播放无需管理员权限。
