# Spec Delta

## Purpose

规范 macOS 打包应用在外部动画调用和管理界面操作之间的激活边界，保证动画反馈不会打断调用应用的键盘输入，同时保留用户明确打开管理界面时的窗口、Dock 和菜单栏交互能力。

## ADDED Requirements

### Requirement: 打包版播放保持当前输入焦点
系统 MUST 在 macOS 打包版通过有效播放链接或 CLI 播放动画时，保持调用前的前台应用和键盘输入焦点，不因播放激活 MotionCue、显示或聚焦管理窗口。该保证 SHALL 覆盖动画开始、播放和结束，不以事后恢复焦点代替。

#### Scenario: 后台常驻时从其他应用播放
- **WHEN** 管理窗口已关闭，用户在其他应用输入时通过有效播放链接触发动画
- **THEN** 动画正常播放，输入持续进入原应用，管理窗口和 Dock 保持隐藏

#### Scenario: 管理窗口可见但处于后台
- **WHEN** 管理窗口可见但其他应用拥有输入焦点，外部播放请求到达
- **THEN** 动画播放且原应用继续接收输入，管理窗口的可见性和 Dock 状态不因播放改变

#### Scenario: 连续播放和首次创建覆盖窗口
- **WHEN** 打包版首次创建动画覆盖窗口或连续收到多个有效播放请求
- **THEN** 所有播放阶段均不改变当前输入焦点，覆盖窗口继续鼠标穿透且不可交互

### Requirement: 协议冷启动保持后台身份
系统 MUST 在 macOS 尚无运行实例时，通过播放链接启动打包版并完成播放，全程不激活管理界面、不显示 Dock、不打断原应用输入，且只建立一个常驻实例。

#### Scenario: 完全退出后链接触发播放
- **WHEN** MotionCue 已完全退出，其他应用通过有效播放链接调用动画
- **THEN** 单个后台实例启动并显示菜单栏图标、播放动画，原应用持续接收键盘输入

### Requirement: 显式打开与播放唤醒分别处理
系统 SHALL 仅在用户明确请求打开管理界面时恢复 Dock、显示并聚焦管理窗口；播放链接伴随的应用重开或启动事件 MUST 不被解释为管理界面打开请求。

#### Scenario: 链接与重开事件顺序不同
- **WHEN** 同一次播放唤醒中，系统以不同顺序或延迟投递链接与应用重开事件
- **THEN** 系统仅播放动画，不执行管理窗口显示或聚焦动作

#### Scenario: 用户主动打开管理界面
- **WHEN** 用户通过 Finder 正常启动、菜单栏打开或检查更新、CLI open 明确请求管理界面
- **THEN** 系统显示并聚焦同一个管理窗口，恢复 Dock，保留菜单栏入口且不产生重复实例

#### Scenario: 管理窗口关闭后再次播放
- **WHEN** 用户关闭已打开的管理窗口后再次从其他应用调用动画
- **THEN** 应用继续后台运行，Dock 保持隐藏，动画播放不打断原应用输入
